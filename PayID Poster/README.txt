PRINTING
- Open the PDF, choose the same paper size (A4 or A5), scale "Actual size" / 100%, colour on.
- Do NOT use "Fit to page" or "Shrink" - it changes the size of the QR code.
- Print one copy first and scan the QR code with your phone before printing more.

QR code: https://panhahun.github.io/Sukii-PayID/   (payment-qr.png is the code on its own)

source/  = editable HTML files. To change the link, make a new QR code and replace source/assets/payment-qr.svg
